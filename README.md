# ASR-Based Speech-to-Text and Text Analysis System

## 📌 Project Overview

This project is a web-based Automatic Speech Recognition (ASR) system that converts human speech into text.

The application also performs basic text analysis on the recognized speech.

## 🎯 Objectives

- Convert speech into text
- Perform Automatic Speech Recognition
- Analyze the recognized text
- Count words
- Count characters
- Count sentences
- Copy the generated text
- Download the transcription

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Web Speech API

## 🔄 System Workflow

User Speech
↓
Microphone
↓
Automatic Speech Recognition
↓
Speech-to-Text
↓
Text Output
↓
Text Analysis
↓
Word / Character / Sentence Count
